1. 环境准备

  • Node.js 20+（建议配合 pnpm）
  • Python 3.13（建议配合 uv）
  • Docker + Docker Compose（PostgreSQL / Redis / Milvus）
  • 可用的 Embedding API Key（如 SiliconFlow）

2. 本地启动

2.1 启动基础依赖

docker compose up -d postgres redis etcd minio standalone attu

2.2 启动后端

uv sync --directory backend --group dev
cd backend
cp .env.example .env
uv run backend

2.3 启动前端

pnpm install --dir frontend
pnpm --dir frontend dev

默认访问：前端 http://127.0.0.1:3000，后端 http://127.0.0.1:8000。

3. 云端部署（不编译前端）

如果云端 pnpm build 卡住，可以用本地打包好的 .output 直接部署。

# 服务器上
mkdir -p ~/lawyer/frontend-prebuilt
cd ~/lawyer/frontend-prebuilt
unzip frontend-output-20260406.zip

cd server
export HOST=0.0.0.0
export PORT=3000
export NUXT_PUBLIC_API_BASE="http://你的服务器IP:8000/api/v1"
node index.mjs

后端云端启动建议

cd ~/lawyer/backend
export FRONTEND_ORIGINS="http://你的服务器IP:3000,http://localhost:3000,http://127.0.0.1:3000"
export AGENT_ENABLED=false
uv run uvicorn app.main:app --host 0.0.0.0 --port 8000

4. Docker 依赖离线导入

云端无法拉镜像时，用本地导出的 tar 包导入：

docker load -i lawyer-infra-images-20260406.tar
docker compose up -d postgres redis etcd minio standalone attu

包含镜像：postgres:16、redis:7-alpine、milvusdb/milvus:v2.5.14 等。

5. 核心环境变量

后端常用

DATABASE_URL=postgresql+psycopg://postgres:postgres@127.0.0.1:5433/lawyer
FRONTEND_ORIGINS=http://127.0.0.1:3000,http://localhost:3000
MILVUS_URI=http://127.0.0.1:19530
REDIS_URL=redis://127.0.0.1:6379/0

前端常用

NUXT_PUBLIC_API_BASE=http://127.0.0.1:8000/api/v1

云端必须改成服务器可访问地址，不要写 127.0.0.1（除非前后端同端口代理）。

6. 切换 Embedding 模型

当前项目支持切换，但需要保证 VECTOR_DENSE_DIMENSION 与模型真实输出维度一致。

# 例：Qwen/Qwen3-Embedding-8B（4096维）
EMBEDDING_BASE_URL=https://api.siliconflow.cn/v1
EMBEDDING_API_KEY=sk-xxxxxxxx
EMBEDDING_MODEL=Qwen/Qwen3-Embedding-8B
VECTOR_DENSE_DIMENSION=4096
VECTOR_SPARSE_DIMENSION=262144

切换维度后建议重建向量索引（Milvus 集合结构里 dense 维度是固定字段）。

7. 常见报错排查

A. 浏览器提示 Failed to fetch

  • 检查前端是否把 API 指向了错误地址（常见误写 127.0.0.1）。
  • 检查后端 CORS：FRONTEND_ORIGINS 是否包含前端真实域名/端口。
  • 检查安全组和端口放行（3000/8000）。

B. 后端日志显示 Uvicorn running on 127.0.0.1

说明只监听了回环地址。请改为：

uv run uvicorn app.main:app --host 0.0.0.0 --port 8000

C. 向量化失败：HTTP 403 balance is insufficient

这是 Embedding 供应商账户余额不足，不是代码 bug。充值或更换可用 API Key 后重试。
